# Book Management Module

## Overview
The Book Management module is part of the Smart Library Management System. It handles the basic management of books in the library, allowing users to add, view, and delete book records.

## Features
- Add new books with a unique Book ID, title, and author.
- View all books registered in the library.
- Delete books using their Book ID.
- Maintain book records using an ArrayList.
- Prevent operations on books that do not exist.

## Technologies Used
- Java
- ArrayList
- Object-Oriented Programming

## File
`BookManagement.java`

## How to Run
1. Make sure Java JDK is installed.
2. Open the project folder in Visual Studio Code.
3. Compile the Java file:

   ```bash
   javac BookManagement.java
   ```

4. Run the application using its main method:

   ```bash
   java BookManagement
   ```
